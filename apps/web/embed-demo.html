Host page: Sentinel Assess embed demo

This page stands in for an integrator portal. It embeds Sentinel Assess two ways.

1. iframe

<iframe src="https://app.example/" allow="camera; geolocation" title="Sentinel Assess"> The app runs on its own origin with its own URL routing and service worker.

2. Web component

<script type="module" src="https://app.example/sentinel-assess.js"></script> then <sentinel-assess initial-path="/library"></sentinel-assess>. Renders in a shadow root with an in-memory router, so host styles and the host URL are untouched.
