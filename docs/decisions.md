| D-019 | 2026-11-04 | `app_user` is a global table with no tenant data. | D-021 | 2026-11-04 | Refresh tokens: 256-bit opaque values, stored as SHA-256, rotated on every refresh within a `family_id`; presenting a rotated token revokes the whole family.
